
## graphify knowledge graph

A knowledge graph of this repo lives in `graphify-out/`.
- Orientation: read `graphify-out/GRAPH_REPORT.md` and navigate it instead of grepping.
- Query: `graphify query "<question>"` (needs the `graphifyy` package; AST-only, no API cost).
- After code changes: `graphify update .` to refresh the graph (no API cost).
